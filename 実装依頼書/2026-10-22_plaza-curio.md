## 1. 目的

装備品のうち 19 品は、このゲームだけの名前の品(独自品)のままです。闇市の大改修の方針は「品ぞろえを SRD 5.1 に沿って並べ直す」なので、独自品を SRD の品の名前へ置き換えます。**数値は 1 つも変えず、名前と説明文だけを変えます。**

もう 1 つ、地下街の古物商(#98 で場所だけ作った露店)で、**牙貨で装備品を買える**ようにします。いまは闇クエストで貯めた牙貨の使い道が消耗品だけで、ゲート付きの装備品はボスの落とし物でしか手に入りません。

**ユーザー決定(2026-10-22)**:

- 対応表は §2-1 の推奨どおり 19 品すべて置き換える。合い方の弱い 4 品(熔鉄の戦鎚・囁きの護符・雷鳴の斧・吸命のメイス)も置き換え、説明文には今の効き目をそのまま書く。
  - 不採用: 「合う SRD 品が無い 2 品(雷鳴の斧・吸命のメイス)は今の名前を残す」。
- 残影の首飾り(隠し要素「残影の獣」の落とし物)も **クロークオブディスプレイスメント** へ置き換える。説明文で残影の獣とのつながりは残す。
  - 不採用: 「残影の獣と対の名前なので残す」。
- 古物商の品ぞろえ = **ゲート付きの 21 品のうち、まだ持っていない品を、来るたびに 1〜2 品**並べる。残影の首飾り(→クロークオブディスプレイスメント)は隠し要素の報酬なので売らない。
  - 不採用: 「装飾品 11 品だけ」「21 品を常に全部並べる」(落とし物の希少さが消える)。
- 値段 = **武器・鎧 30 牙貨 / 装飾品 25 牙貨**。
  - 不採用: 「全部 20」「全部 40」。

### 2-3. ⚠⚠⚠ 罠 A — 名前の移し替えを 1 か所だけに当てると、ダンジョンから入った古いセーブで持ち物が消える

## 5. STEP2 — 古いセーブの名前の移し替え(罠 A・罠 B)

両ファイルに同じ中身で置く(index は `DF_SHEET_GATED_LEGACY` の隣、酒場は `DF_GATED_LEGACY` の隣):

```js
// ★[#99] 独自品 → SRD の品へ改名した 8 品の旧名 → 新名。gated の所持は名前キーなので、読んだ直後に必ず通す。
//   ⚠ index.html / tavern.html で同じ中身にすること。⛔ ここ以外に旧名を書かない (verify_plaza_curio (1c) が数える)。
const DF_GATED_RENAME = {
  "聖別された剣": "サンブレード", "熔鉄の戦鎚": "ドワーヴンスロウワー", "贖罪のメイス": "メイスオブディスラプション",
  "星詠みの杖": "スタッフオブフロスト", "風斬りの弓": "オースボウ", "吸命の短剣": "ソードオブライフスティーリング",
  "山守りの板金鎧": "ドワーヴンプレート", "軽業師の革装束": "グラマードスタデッドレザー",
};
function dfRenameGatedNames(arr) {   // 旧名を新名へ・重複を落とす。変わったかどうかも返す
  const out = []; let changed = false;
  for (const n of arr) { const m = DF_GATED_RENAME[n] || n; if (m !== n) changed = true; if (!out.includes(m)) out.push(m); else changed = true; }
  return { names: out, changed };
}
```

- 酒場 `dfLoadGatedOwned`: 配列が読めたら `dfRenameGatedNames` を通し、`changed` なら `dfPersistGatedOwned` で書き戻してから `Set` を返す。
- index `dfSheetGatedOwned`: 配列が読めたら `dfRenameGatedNames(arr).names` を返す(書かない)。
- index `markGatedOwned`: 読んだ `cur` を `dfRenameGatedNames` に通してから `add(name)` して書く。
- 種まきの表 2 つの 2 名を新しい名前へ(§2-4)。

⚠ 関数名・定数名は両ファイルで同じにしてよい(別ページなので衝突しない)。index は classic script 直下なので、検証から見たいときは §8 の計測機構の方法で(本番に検証専用の行を足さない)。
