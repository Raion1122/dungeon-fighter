## 1. 目的

酒場の地図には卓が 3 つあるのに、依頼が出るのは 2 卓だけで、1 卓は常に空いている。
しかも 2 件のうち 1 件は必ず「本筋の最前線」なので、**自由に選べる依頼は実質 1 件**しかない。
依頼は全部で 12 本(本筋 6 + 脇道 6)あり、終盤は 12 本とも解放済みなのに 2 本しか見えない。
ユーザー要望:「酒場で受注できるクエストを増やしたい。今、卓にある 2 種からしかいけないから。」

これを **3 件**(本筋 1 + 自由枠 2)にする。絵・歩行格子・札の位置は一切変えない。

**ユーザー決定(2026-11-23)**:

- 採用 = **候補① 3 卓とも使う**。
- 不採用:
  - ② 主人に一杯おごって依頼人を呼ぶ: 引き直しの口が 2 か所になり、#81 の「消し口は 1 つ」を崩す。
  - ③ 依頼の掲示板: 新しい UI が要る。載せる範囲を広げると卓が飾りになる。
  - ④ 卓を 5 つに改装: codex1 への MAP 発注から MASK の作り直しまで要り、重い。次回以降の「酒場の改装」へ回す。
- 開始直後(解放済みが廃坑 + 巣穴の 2 本だけ)の 3 卓目は、**「次の未解放」を ??? で出す**。#81 の「次があることが見える」をそのまま使う。
- 更新前に保存された 2 件の盤面は、既存の「不正なら引き直す」道で **1 回だけ** 3 件へ入れ替わってよい。新しい移行処理は作らない(会議 第 2 段の折衷。本筋の最前線は必ず残る)。

### 2-2. ⚠⚠⚠ 罠:`BOARD_SIZE` を 3 にするだけだと、`?warren=0` で読み込むたびに引き直す

`drawBoard` は「本筋 + 解放済み + 次の未解放 1 件」までしか積めない。積める上限は次の値になる。

    min(BOARD_SIZE, 解放済みの数 + (次の未解放があれば 1))

`boardValid` の `:11816` は「**ちょうど** `BOARD_SIZE` 件」を要求する。上限が 3 に届かない世界では、
`drawBoard` が作った盤面を `boardValid` が毎回不正と判定する。すると `loadOrDrawBoard` は読み込むたび
(`buildSigns` は `__tavernRefreshSigns` 経由で何度でも呼ばれる)に引き直し、**札の席が跳ね、nonce が毎回変わる**。

| 世界 | 解放済み | 次の未解放 | 上限 | BOARD_SIZE=3 で |
|---|---|---|---|---|
| 本番の開始直後 | 廃坑・巣穴(2) | 森 | 3 | 通る(廃坑・巣穴・??? 森) |
| **`?warren=0` の開始直後**(`:3921` が `kobold-warren` を配列から外す) | 廃坑(1) | 森 | **2** | ⚠ **毎回不正 → 毎回引き直し** |
| 本番で廃坑クリア後 | 4 本以上 | — | 3 | 通る |

`?warren=0` は撤退スイッチだが、検証が使う世界でもある(`verify_tavern_map` の ??? 判定 `:1320`、`verify_kobold_warren` (1c) の `offDraws` `:492`)。

⇒ **件数を数える関数を 1 つにまとめ**(例 `boardCount(f)`)、`drawBoard` の打ち切りと `boardValid` ① の両方がそれを使う。

## 4. STEP1 — 件数関数と BOARD_SIZE

```js
    var BOARD_KEY = "dragonfighters.questBoard";
    /* ★[#120] 卓の依頼は 3 件 (3 卓とも使う)。撤退 ?board3=0 で #81 の 2 件へ戻す。 */
    var BOARD_SIZE = BOARD3_ON ? 3 : 2;
    /* ★[#120] 盤面の件数 = 積める上限。drawBoard と boardValid が **同じ値** を使う。
       ⚠⚠ boardValid が「ちょうど BOARD_SIZE 件」を要求すると、解放済み + 次の未解放が
         BOARD_SIZE に届かない世界 (?warren=0 の開始直後 = 廃坑 + ??? 森の 2 件) で
         毎回不正 → 読み込むたびに引き直しになる (依頼書 #120 §2-2・変異 fixedcount)。 */
    function boardCount(f) {
      return Math.min(BOARD_SIZE, f.unlocked.length + (f.nextLocked ? 1 : 0));
    }
```

- `boardValid` ①: `keys.length !== BOARD_SIZE` → `keys.length !== boardCount(f)`
- `drawBoard`: 打ち切りの `BOARD_SIZE` を `boardCount(f)` へ(結果は同じだが、2 つの関数が同じ数を見ていることを明示する)
- ⛔ `:11825` の未解放を許す条件、本筋を必ず入れる ③、席の無作為な割り当ては変えない
