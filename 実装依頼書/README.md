## 使い方

1. こちらの窓で計画を 1 件 = 1 ファイルとして起草する
2. ユーザーが内容を確認・承認する
3. 実装窓に「`実装依頼書/<ファイル名>` を読んで実装して」と渡す
4. 実装が終わったら見出しのステータスを `完了 <コミットハッシュ>` に更新する

## 命名規則

`YYYY-MM-DD_<slug>.md`(例: `2026-08-20_mine-detour-balance.md`)
slug は英小文字ケバブケース。1 ファイル = 1 まとまりの実装単位。

## 依頼書の書き方(最低限これだけは書く)

- **ステータス**: 起草中 / 承認済 / 実装中 / 完了 `<hash>`
- **目的**: 何を実現したいか(手段ではなく目的で書く)
- **背景・現状**: 今どうなっているか。関連ファイルは `index.html:1234` 形式で指す
- **変更範囲**: 触るファイルと、触らないと決めたファイル
- **受入条件**: 実装窓が自分で「終わった」と判定できる条件。可能ならドライバ名まで書く
- **撤退スイッチ**: `?feature=0` 形式の URL パラメータ名(本プロジェクトの慣習)
- **やらないこと**: スコープ外を明示して、実装窓の暴走を防ぐ
