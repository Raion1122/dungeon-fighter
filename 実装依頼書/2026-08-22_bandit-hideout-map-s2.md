## ⚠⚠⚠ 着手前に必ず実測する 3 点 (STEP1)

### (A) `outdoor: true` × 「敵の居る屋外部屋」は**前例が無い**

`index.html:31977` 付近のコメントが**名指しで警告している**:

> ⚠⚠ visitedTiles も**一緒に**立てる。あれは `findNearestAliveEnemy` の「未発見の敵は無視」が
> 読む Set なので、片方だけ立てると「画面には見えているのに誰も反応しない敵」が生まれる。
> **逆に言えばこれは索敵の挙動を変える**: 屋外の部屋では最初から部屋中の敵が索敵対象になる。
> **今の唯一の屋外部屋 (goblin-mine/n0) は敵 0 体なので現状は 1 体も動かないが、
> 屋外ノードに敵を置く日には必ず効く。**

**本件がその日**。52x26 の屋外部屋に敵を 5〜10 体置く。測ること:

1. 入場直後 (t=0) に `heroAI` が誰を目標にするか。**最寄りの敵 = 橋の見張りであること**
   (アジトの奥のスカーを目標にして 47 タイル直進しないこと)
2. 敵側は `outdoor` の影響を受けない — 索敵は
   `Math.hypot(...) < DETECTION_RANGE (1200px = 12.5 タイル) **AND** hasLineOfSight`
   (`index.html:16014` = `DETECTION_RANGE`) のまま。**ここは変わらないはず**という予測を実測で確かめる

### (B) 3 つの交戦集団が**融合しないか**

街道は一直線で見通しが良い = **`hasLineOfSight` が素通しになる**。距離だけで安心しない。

- 橋の見張り (global col ≈ 33) ↔ 門番 (global col ≈ 47) = **14 タイル**。
  12.5 タイルまで **1.5 タイルしか余裕が無い**
- 門番 ↔ アジト内の護衛 = 約 6〜8 タイル → **融合する前提**でよい (ボス戦の一部)

⚠ #10 の教訓: **`DETECTION_RANGE` は `AND hasLineOfSight` と対で読む**。
「距離が 14 だから安全」とだけ書いて配置を決めない。

### (C) 座標は書く前に `isTileWall` で 1 マスずつ測る

⚠⚠⚠ #10 で挙げた 3 つの候補座標は**全部岩だった**。

### STEP3 — `buildP6Run` / `p6Node` に上書き口を 4 つ (**挙動不変**の段)

⚠⚠ **触るのは `nd()` だけでは足りない**。`nd()` (`index.html:34108`) は `p6Node` へ

`spec[id]` から取れる上書きを 4 つ足す:

| `d.density` | `1` | 大部屋では **0** (下記⚠) | `nd()` **+ `p6Node`** |
| **`d.start`** | **`{ tx: 36, ty: 13 }`** | n7 の起点を入場地点へ寄せる (下記⚠⚠⚠) | `nd()` **+ `p6Node`** |

⚠⚠ **`density` を `\|\|` で既定値へ落とさないこと**。`0` は falsy なので「散らさない」指定が

(52x26 = 1352 タイル ÷ 9x6 = 54 タイル)。廃坑 n0/n1 が踏んだ罠と同じ。

⭐ **手本が既にある**: `buildGoblinMineRun` の `node()` が `index.html:33936` で実装済み。

⚠⚠⚠ **`start` を足す理由 (これが無いと無言で欠陥が入る)**。
`buildNode` は `index.html:32077` で **起点のタイルを問答無用に床へ彫る**:

```js
if (!IS_FIELD_THEME && mapData[START_TY][START_TX] === 1) mapData[START_TY][START_TX] = 0;
```
