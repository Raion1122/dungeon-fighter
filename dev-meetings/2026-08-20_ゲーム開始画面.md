## 第1ラウンド：ブレスト(各専門から毛色の違う方向性を1つ)

【ガイウス】私は**名乗りの儀**を推す。タイトルで「新規」を選んだら、いきなりクラス一覧を並べるんじゃない。DM が問うんだ——「汝は何者か」。そこに6つの答えが並ぶ。「剣を取った男」「山の民」「森の子」……クラス名ではなく**一人称の答え**で選ばせる。選んだら「では、そなたを○○と呼ぼう」と返して酒場へ送り出す。**ゲームブックの1ページ目**だよ、これは。

# 実装候補(方向性を選んでください)

## 候補①：酒場の前段にタイトル層を1枚(最小)
- **ジャンル**: システム／最小改修
- **狙い**: `tavern.html` 内に `#titleOverlay` を足すだけで「新規／続き」を成立させる
- **中身**: ロゴ + 「はじめから」「つづきから」。新規は既存 `wipeAdventureRecord()` を呼んでから前口上 → キャラ選択。続きはオーバーレイを閉じて酒場へ
- **ざっくり規模**: 小(半日〜1日)
- **既存流用度**: 高(prologueOverlay / wipeAdventureRecord / selectHero を全部流用、新規ファイルなし)
- **iOS Safari**: クリア(最初のタップがアンロックを兼ねる)
- **推し**: レンツ ／ **慎重**: ミサキ(「地味。ロゴだけだと寒い」)

## 候補②：`title.html` を新設して起動先を差し替え
- **ジャンル**: QoL／起動性能
- **狙い**: 6,275行の酒場を読む前に軽いタイトルを出し、「起動した感」を早める。将来のスロット選択・設定・クレジットの置き場にもなる
- **ざっくり規模**: 中(1〜2日)
- **既存流用度**: 中(前口上とナレ資産が酒場側にあるため、移設か二重持ちが要る)
- **iOS Safari**: 要注意(ファイル分割で BGM アンロックが2回に割れる)
- **推し**: ノエル(当初) ／ **慎重**: レンツ(「**3枚目のファイルは恒久コスト。ロード時間を測ってからにしろ**」)

## 候補③：「汝は何者か」— 名乗りの儀でキャラ選択をRP化
- **ジャンル**: シナリオ／体験設計
- **狙い**: クラス選択を「一覧から選ぶ作業」から「名乗る儀式」に変える。ゲームブックの1ページ目にする
- **中身**: DM が問う → 6つの一人称の答え → 選ぶとその下に性能が開く → 「では、そなたを○○と呼ぼう」で酒場へ
- **ざっくり規模**: 中(文章6本 + 演出。①か④の上に載る)
- **既存流用度**: 中(prologueOverlay のナレ機構をそのまま使える。文章は新規)
- **iOS Safari**: クリア
- **推し**: ガイウス ／ **慎重**: ノエル(「性能を併記しないと初見が詰まる」→ 折衷で解決済み)

## 候補④：銀の鹿亭の扉が開く(酒場そのものをタイトルにする)
- **ジャンル**: 演出／ビジュアル
- **狙い**: 専用画面を作らず、初回は酒場に暗幕を落として暖炉の火だけ透かし、選択後に暗幕が抜けて酒場が明るくなる
- **ざっくり規模**: 小〜中(新規アセットはロゴ1枚)
- **既存流用度**: 高(`#tavern` の背景・暖炉をそのまま使う)
- **iOS Safari**: クリア(ただしタイトル用BGMを足すなら別チケット)
- **推し**: ミサキ ／ **慎重**: レンツ(「①と実質同じ器。**違うのは見せ方だけ**」)

## 第1ラウンド：設計

【レンツ】**死に場所その1: 3スロットのキー改名。** さっき俺が言った「`df.slot1.*` へ改名する大手術」は**撤回する。改名しなくていい方法がある。**

【レンツ】効き目は3つ。① **72箇所のキー参照を1文字も触らない**(tavern 35 + index 37)。② **ライブが常に真の状態**だから、ブラウザが落ちても現在のスロットは絶対に失われない。失われうるのは「他のスロットへ移った時に直前の進行が一覧の要約に載らない」だけだ。③ 既存の `wipeAdventureRecord()`(`tavern.html:5239`)が**すでに prefix 総なめで書けている**から、「新規」はその関数をそのまま呼べる。

【ガイウス】筋がいい。**セーブは1つ、棚が3つ**ということだな。

【ノエル】**死に場所その2 は私が言う。`title.html` に前口上を持っていかないで。** あそこは羊皮紙の CSS も `playNarration()` も VOICEVOX の manifest 読み込みも全部酒場側の資産。3枚目のファイルに複製したら、レンツさんが恐れてた恒久コストがそのまま乗る。

【ミサキ】でも「はじめから」を押した直後に前口上が来ないと、間が抜けません?

【ノエル】**来ればいいの。場所が酒場でいいだけ。** `title.html` は「スロット選択 → 名乗り」で終わって `tavern.html` へ飛ばす。新規なら wipe 済みで `prologueSeen` が消えてる → **酒場の `initTavernPrologue()` が何もしなくても自動で語り出す。** プレイヤーから見れば連続した1本の流れ。

【レンツ】……それだ。**title.html が軽くなる**からノエルの当初の狙い(起動が速い)も同時に取れる。ロゴとスロット3枚とクラスカード6枚しか載らない。

【ミサキ】納得。**じゃあ演出の重心はタイトルじゃなく「名乗り → 酒場の扉」に置きます。**
