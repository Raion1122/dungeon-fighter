## 第1ラウンド：ブレスト（各専門領域から方向性を1つ）

**【ガイウス】** まず枠を決めよう。沼地には既にハイドラという立派な隠し要素がある。そこへ**2つ目の隠し要素**を足すのは筋が悪い。Gold Box でもな、隠し部屋が2つある階は「どっちも薄い」と言われたものだ。だから今回足すのは**本線の導線上に立つ小ギミック**であるべきだ。廃坑の従者もそうだった — あれは隠し要素じゃない、通り道に縛られていたんだ。で、私の案は**供物の杭**だ。リザードマンがハイドラへの供物として、人間を沼の杭に縛って沈めかけている。助けるか、見捨てて奥へ急ぐか。EV-5 の直系だ。

**【レンツ】** 実装から言うと、ガイウスの案は一番安い。`registerNodeEvent` が既に汎用化されていて、EV-2/5/9 が現にそこへ乗っている（`index.html:35352`）。`{key, nodeId, spot, run}` の 1 登録で 3 択が立つ。ただし**同行者システムは「シナリオ1限定」とコードに書いてある**（`:20969`）ので、「助けたら仲間が増える」まで欲張ると汎用化工数が別途乗る。私が出す方向性は別物で、**第三勢力**だ。森の `cageSpawns` + `linkCagedBeasts` はシナリオ属性として既に汎用で、沼側は 1 行足すだけで動く。リザードマンが泥沼の罠に沈めた「沼の主」を解き放つ。

**【ミサキ】** その第三勢力、絵としては最高に映えるんだけど — レンツ、檻のスプライト見た？ `cage_closed.png` は**鉄格子**なの。沼の真ん中に鍛冶で組んだ鉄檻が置いてあったら嘘でしょ。蔦の網か、泥に沈めた木組みの杭に描き直さないと画面が破綻する。で、私の方向性は**盤面そのものを仕掛けにする**やつ。せっかく 1 枚絵に焼くんだから、絵の中に「水位の違う浅瀬」を描き込んでもらって、**堰を切ると水が引いて新しい足場が出る**。マップ化とギミックが同じ1枚で完結するのが気持ちいい。

**【ノエル】** はい冷や水。ミサキのそれ、**このゲームはオートバトルです**。プレイヤーは歩く経路を選べません。足場が増えても、増えたことを味わうのはプレイヤーじゃなくて経路探索アルゴリズムです。「水が引いた！」の 2 秒後に AI が勝手に最短路を引き直して終わり。……で、私の方向性は**警報**。沼の水面に骨の鳴子が張ってあって、踏むと族長の巣に増援が湧く。盗賊が居れば事前に察知して切れる。これは**編成の判断に効く**ので、出発前準備しか関与できないこの game で唯一プレイヤーの手が届く層に刺さります。

**【ガイウス】** ノエル、それは good だ。だが1つ足すなら、**ファラクサスの伏線**も置いておきたい。開幕ナレの「まるで誰かの命令に従うかのように…」が回収されないまま3年経っている。若い司祭と話せる分岐を置けば、神殿の霊（シナリオ5）と同じ器で伏線を渡せる。

## 第2ラウンド：絞り込み（制約で間引く）

**【ノエル】** ミサキの水位案、正直これ落とすべきです。オートバトルで「地形が変わる」の価値は、プレイヤーが**変わる前と後を見比べられる**時だけ成立する。この game の潜行は一本道で、同じ部屋を2回歩きません。実装は重い、体感はゼロ。落としましょう。

**【ミサキ】** ……悔しいけど、そこは認める。じゃあ水位は捨てて、**演出だけ**残させて。堰じゃなくて「祭壇へ続く参道が水面下に沈んでいて、松明を灯すと水面に道筋が浮かぶ」みたいな**見せるだけの仕掛け**。これなら経路には触らない。

**【レンツ】** それは第4の案じゃなくて、どの案にも足せる**塗り**だな。候補としては立てず、選ばれた案の演出欄に持っていこう。……で、私からの間引き。ガイウスの司祭対話案、**器は temple-ghost と同じで安いが、ファラクサスの伏線は「セリフを足すだけ」で済んでしまう**。それはギミックじゃなくてテキストだ。「細かいギミックを載せたい」という今日の議題に対しては弱い。単独候補として立てるなら、対話の結果が**盤面を動かす**必要がある。

**【ガイウス】** ならこうしよう。司祭と話して交渉に成功すると、**族長の巣の護衛が2体減って外へ出ていく**。数字が動けばギミックだ。

**【レンツ】** それなら立つ。あと全案に共通する地雷を先に言っておく。森 n7 の注記が明言している —「**マスクで塞いだタイルに敵を置くと穴が開く**」。今回追加する杭も檻も鳴子も、**全部 MASK の `.` のマスに置く**こと。それと `index.html` を触る以上、**changelog の 1 行が機械強制される**（`scripts/hooks/pre-commit`）。今回はプレイヤーに見える変化があるので問題ないが、忘れるとコミットが止まる。

**【ノエル】** もう1つ。**8ノードのままにするのか、森みたいに1ノードへ畳むのか**を先に決めないと、ギミックの置き場所が決まりません。畳んだら n6「蛇神の祭壇」が消えて、**ハイドラの置き場所が無くなる**。既に出荷済みの隠し要素を壊すのは論外です。

**【レンツ】** 正確に言うと、畳んでも祭壇を大部屋の中へ移せば動く（森が `NODE_EXTRA_SPAWN_KINDS` で search/loot を兼務させたのと同じ理屈）。ただし `SCENARIO_NODE_EXTRAS` の座標 `[36,13]` を大部屋座標へ打ち直す作業が乗る。**畳むかどうかは今日決めなくていい**が、依頼書では必ず 1 択に固定すること。両睨みで書くと実装窓が止まる。

**【ガイウス】** よし。候補は4つに整理された。ミサキの水位は落とし、演出は塗りへ格下げ。司祭案は「護衛が減る」を条件に生き残り。

# 実装候補（方向性を選んでください）

> **全候補に共通する前提（= 依頼書の前半）**
> codex1 へ沼地の卓上バトルマップ 1 枚を新規発注 → `--fit` で焼き込み格子を実測 → `make_grid_map.py` の `GRIDS` へ 1 キー追加 → `assets/room_lizard-swamp_<key>.jpg` を焼く → `ROOM_PAINTINGS_DEF["lizard-swamp"]` に `blocked` マスクを書く → `buildLizardSwampRun()` の該当ノードを `{rect, paint, density:0, start, slots, boss}` へ差し替え。
> ⭐ 森 n7（`n7big`）と**完全に同じ経路**で通る。`lizard-swamp` は屋外テーマではないので #52 の罠はかからない。

## 候補①：供物の杭 — 沼に沈められかけた生贄
- **ジャンル**: NPC 救出イベント（廃坑 EV-5「捕らわれた従者」の直系）
- **狙い**: 本線の導線上に「助けるか、急ぐか」の 3 択を置き、族長戦の難度を分岐させる
- **中身**: 参道の途中、水面から突き出た杭に人間が縛られている。潮は少しずつ上がっている。〈縄を切る(DEX)〉／〈杭ごと引き抜く(STR)〉／〈見捨てて先へ〉。救出すると族長戦で「族長が人質を取る」分岐が無効化される（グリクス戦と同じ構造）
- **ざっくり規模**: 小〜中
- **既存流用度**: **高** — `registerNodeEvent` 1 登録 + `runServantEvent` と同型の run 関数。ただし「同行者が増える」まで欲張ると汎用化工数が別途（現状シナリオ1限定）
- **iOS Safari**: クリア（3択ダイアログは既存の共用器）
- **新規アセット**: 杭に縛られた NPC 1 枚（`servant_captive` の色替えで済む可能性あり = 要実測）
- **推し**: ガイウス ／ **慎重**: レンツ（同行者化に手を出すと膨らむ）

## 候補②：沼の主 — 泥に沈められた第三勢力
- **ジャンル**: 第三勢力ミニボス（森「残影の獣」の直系）
- **狙い**: 敵味方を区別しない獣を戦場に解き放ち、戦術的な博打を作る
- **中身**: リザードマンが泥沼の罠に沈めて飼い殺している大型獣（`ruinSpider` 流用 or 新規の巨大鰐）。解放すると PT もリザードマンも無差別に襲う。酒場の噂で場所を掴んでいないと存在しない（`s3_*_intel` を 1 つ追加）
- **ざっくり規模**: 中
- **既存流用度**: **高** — `cageSpawns` + `linkCagedBeasts` はシナリオ属性として既に汎用。敵も `ruinSpider` が出荷済み
- **iOS Safari**: クリア
- **新規アセット**: ⚠ **檻スプライトが鉄格子** (`cage_closed.png`)。沼には嘘なので「蔦の網／泥に沈めた木組み」の差し替えを codex1 へ 1 件発注が要る（ミサキの必須条件）
- **推し**: レンツ・ミサキ ／ **慎重**: ガイウス（隠し要素が沼に2つになる = ハイドラが薄まる）

## 候補③：骨の鳴子 — 踏めば増援が来る警報線
- **ジャンル**: 罠／編成が効く警報ギミック
- **狙い**: オートバトルでプレイヤーの手が唯一届く「出発前の編成」に報いる。盗賊を連れた回とそうでない回で盤面が変わる
- **中身**: 参道の浅瀬に骨と貝殻の鳴子が張ってある。踏み抜くと族長の巣へ音が伝わり、ボス部屋の護衛が +2 体。盗賊が居れば接近時に自動察知 →〈切る〉で無効化。既存の罠解除システムと同じ判定を通す
- **ざっくり規模**: 小
- **既存流用度**: **高** — 罠解除システム（`project_trap_disarm`）+ ボス部屋 `slots` の条件分岐だけ
- **iOS Safari**: クリア（新規 DOM ほぼ無し）
- **新規アセット**: 鳴子の平置きプロップ 1 枚（`swamp_detail.png` の追加コマでも足りる可能性 = 要実測）
- **推し**: ノエル ／ **慎重**: ミサキ（地味。画面の見せ場が小さい）

## 候補④：若い司祭の逡巡 — 交渉で護衛が減る
- **ジャンル**: 対話分岐（シナリオ5「神殿の霊」の器を先行実装）
- **狙い**: 開幕ナレの「誰かの命令に従うかのように…」= **ファラクサスの伏線を初めて回収する**
- **中身**: 祭壇の手前に、供物を捧げるのをためらっている若い `lizardPriest`。戦わずに話しかけられる。〈古代文字を読む(INT)〉／〈信仰を突く(WIS)〉／〈脅す(CHA)〉。成功すると司祭は一族を連れて退き、**族長の巣の護衛が 2 体減る**。失敗すると逆に +1 体
- **ざっくり規模**: 中
- **既存流用度**: **中** — `registerNodeEvent` + `showCharChoice` + `js/skill-check.js` は全部ある。ただし「敵として湧いている個体を会話可能にする」= `passiveNpc` 経由の新しい配線が要る（ハイドラの封印中と同型だが、雑魚に適用した前例はまだ無い）
- **iOS Safari**: クリア
- **新規アセット**: なし（`lizardPriest_anim.png` 出荷済み）
- **推し**: ガイウス ／ **慎重**: レンツ（「テキストだけ」に堕ちやすい。護衛±が入って初めてギミック）

## 会議で落とした案（記録）

- **水位ギミック（堰を切ると足場が出る）** — ノエルが却下。**オートバトルなので経路をプレイヤーが選べず、地形変化の体感がゼロ**。実装は重い。
  - ただしミサキの折衷「**水面下の参道が松明で浮かび上がる**（経路には触らない見せるだけの演出）」は、**選ばれた候補の演出欄へ塗りとして持っていく**ことで合意。

## 依頼書を書く前に必ず決める 1 つ

**8ノードのまま n4 or n7 だけ大部屋にするのか、森のように 1 ノードへ畳むのか。**
畳む場合、n6「蛇神の祭壇」が消えるので**ハイドラの座標 `[36,13]` を大部屋座標へ打ち直す**作業が乗る（`SCENARIO_NODE_EXTRAS` / `index.html:10462`）。
⛔ 両睨みで依頼書を書かないこと。実装窓が止まる。

**【レンツ】** 測ってきた。結論から言うと**この案は第1段で見積もったより安い**。理由は事実17 — カエルムが全く同じことを既にやってる。`isNpcSpirit` フラグ → `initCaelum()` で `inactive + passiveNpc` → 接近で対話 → 友好/無視/敵対の3ルート。**写経元が完成品として存在する**。私が第1段で「前例なし」と言ったのは間違いだった。

**【レンツ】** ノエル、n7 の slots を実際に見たか。`[[39,12,"lizardWarrior"],[39,15,"lizardPriest"]]` + ボス。⭐ **司祭がちょうど 1 体いる**。だから減らすのは 2 体じゃなくて**この司祭 1 体だけ**でいい。「若い司祭が一族を連れて沼を去ったので、玉座の間に司祭がいない」— 種類が一致してるから納得できるし、盤面は「戦士1 + ボス」で成立する。

**【レンツ】** ⭐ 良い指摘だ。**1番目は「何もしない（立ち去る）」に固定**する。判定を伴う3択はその後ろ。

**【ガイウス】** 判定の中身を決めよう。`SkillCheck.CHECKS` を見たら、ちょうど欲しい3つがある — `history`（歴史・INT・**魔法使いが得意**）、`religion`（宗教・WIS・**僧侶が得意**）、`intimidation`（威圧・CHA・**戦士が得意**）。3つとも得意クラスが違う。これは D&D として美しい。「編成によって通る道が違う」— Gold Box がやっていたことそのものだ。

**【ノエル】** それ、私の候補③（編成が効く）の狙いが④に吸収されたってことですよね。……悪くないです。

# 開発計画書：沼の参道の卓上マップ + 若い蛇神司祭

## 概要

シナリオ3「沼地」の n4「蛇神の参道」を、codex1 納品の卓上バトルマップ 1 枚へ差し替える。
その参道に**戦わずに話しかけられる若い蛇神司祭 `swampNovice`** を 1 体置き、
〈立ち去る／古代文字を読む(history)／信仰を突く(religion)／脅す(intimidation)〉の 4 択を出す。
成功すると n7「族長の巣」から `lizardPriest` が消え、失敗すると `lizardRaider` が 1 体増える。

## 実装スコープ（1フェーズで完結）

**作るもの**
- 沼の参道の卓上マップ 1 枚（codex1 新規発注 → `GRIDS` 焼き付け → `blocked` マスク）
- `buildLizardSwampRun()` の n4 を大部屋 spec へ差し替え
- ENEMY_TYPES に `swampNovice` を 1 キー追加（`lizardPriest_anim.png` 流用）
- `initSwampNovice()` + `tryApproachNovice()`（`initCaelum` / `tryApproachAltar` の写し）
- `sceneFlags.s3_novice_swayed`（true / false / null の 3 値）
- `nodeSpawnsFor()` に n7 の顔ぶれを ±1 する小さなフィルタ
- 撤退スイッチ `?swampmap=0`（大部屋化と司祭の**両方**を旧状態へ戻す）

**作らないもの（明示的に範囲外）**
- ⛔ **8ノード → 1ノードの折り畳み**。n6「蛇神の祭壇」が消えると**出荷済みのハイドラの置き場所が無くなる**
- ⛔ n6 のハイドラ関連コード（`initHydra` / `runAltarDialog` / `SCENARIO_NODE_EXTRAS["lizard-swamp"]`）は **1 バイトも触らない**
- ⛔ n7 を大部屋にすること（今回は n4 だけ）
- ⛔ 同行者システムの汎用化（シナリオ1限定のまま）

## 新規実装

1. **`swampNovice`（若き蛇神司祭）** — ENEMY_TYPES に 1 キー。`lizardPriest` のスタッツをほぼ流用し、幾何（`sheetW/H` `frameW/H` `cols` `rowOffset`）は**流用元と完全一致**。`isSwampNovice: true` を持たせる。⚠ `lizardPriest` の def にフラグを立てない（n4/n7 の全司祭が会話可能になり崩壊する）
2. **`initSwampNovice()`** — `initCaelum()` の写し。`inactive + passiveNpc` にして淡い色味を当てる。`spawnNodeEntities()` の `initHydra()` の隣に 1 行追加。⚠ **`spawnDetourChests()` より前**（あれは必ず最後）
3. **`tryApproachNovice()`** — `tryApproachAltar()` の写し。400ms tick、接近半径は 220（祭壇の実測値を踏襲）
4. **4択ダイアログ** — ⭐ **1番目は必ず「立ち去る」**（`?autoplay` は index 0 を自動選択するため）。2〜4番目が判定つき
5. **`nodeSpawnsFor()` のフィルタ** — n7 入場時に `sceneFlags.s3_novice_swayed` を読んで `lizardPriest` を 1 体落とす／`lizardRaider` を 1 体足す
6. **大部屋 spec** — n4 を `{rect, paint:"n4big", density:0, start:{...}, slots:[...]}` へ

## 分岐の中身
