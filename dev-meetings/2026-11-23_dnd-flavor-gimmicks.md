## 第1ラウンド：ブレスト（各専門から枠付け）

【ガイウス】提案書は良い。sakata の狙いは正しく「D&D らしさ」なんだ。だがいいか、半分は**もう出荷済み**だぞ。呪文スロット(A1)は Phase 2-J で動いてるし、照明と霧(C2)は #39 でとっくに入ってる。掛け合い(B3)も #117〜#119 でやった。会議の仕事は「新機能を 10 個作る」じゃなく、「どれが本当に新しくて、どれが既存の磨き直しか」を仕分けることだ。

【レンツ】同感だ。実測した。A1 はスロット機構そのものは完成してる——90 箇所で `spellSlots` を参照してる。問題は**回復が自動すぎる**こと。戦闘に勝つたび 25% 戻って、部屋クリアで最低位 +1、シナリオクリアで全回復。これじゃ「どこで大魔法を切るか」の緊張が死ぬ。sakata が欲しいのは機構じゃなく**希少性**だ。だから A1 は「新規実装」じゃなく「回復経済のチューニング＋酒場休息」になる。

【ミサキ】C1 も同じ構図ね。画面シェイクはもう `SHAKE_CRIT` で揺れてるし、クリのダメージ数字も `.dmgPop.crit` で大きく出してる。sakata が挙げた 3 つのうち「画面シェイク」「大きな数字」は**済み**。残ってるのは「一瞬のスローモーション」だけ。でもね、テストプレイで一番ウケたのがダイス演出なら、そこをもう一押し磨く価値はある。ヒットストップ一発で打撃の重みは化けるのよ。

【ノエル】待って。全部やる前提で話が進んでるけど、正直に言う。A3（交渉・威圧・説得で敵を味方化）は**地雷**。オートバトルなのよ、これ。プレイヤーは出発前にしか関与しない。その戦闘フローに社交ロールを割り込ませて、成否で敵が味方になったり情報が出たりしたら、敵 AI も報酬もシナリオ分岐も全部巻き込んで壊れる。iPhone 片手で見てる人に「今の交渉、何が起きたの?」って絶対なる。これは見送り一択。

【ガイウス】……ノエルの言う通りだ。A3 は D&D の華だが、オートバトルとは油と水だ。だが完全に捨てるのは惜しい。縮小の芽は残したい。

## 第2ラウンド：絞り込み（対立と折衷）

【レンツ】A2（技能判定イベント拡充）は逆に**本命**だ。`SkillCheck` エンジンがもう完成してる——DC 表示、クリ 20、ファンブル 1、1 部屋 1 ロール。罠・鍵・伝承で実績がある。隠し扉＝知覚、崩れ橋＝運動、碑文＝知識は、**エンジン流用＋イベントデータを書くだけ**だ。新規コードはほぼ要らない。しかも sakata の「ダイス演出を戦闘外へ広げる」に直撃する。

【ガイウス】そこは全面賛成だ。Gold Box でもな、ダンジョンの手応えは戦闘だけじゃない。扉の前で判定に失敗して引き返す、碑文を読んで伏線を掴む——あれが「冒険している」手応えなんだ。A2 は最優先でいい。

【ノエル】A2 は賛成。でも 1 個だけ釘を刺す。判定イベントを増やすなら、**失敗したときの救済**を必ず設計して。オートバトルで「知覚失敗→隠し扉見逃し→二度と戻れない」をやると、プレイヤーは理不尽に感じる。既存の罠解除が「ファンブルだけ被弾」で過度に罰しないトーンにしてるのは正しい。あれを踏襲するなら OK。

【ミサキ】A4（撤退と死亡の重み）はどう? 撤退ボタンはもうあるけど、蘇生費も自動撤退ラインも無い。金貨の使い道を作るって意味では刺さるわよ。

【ノエル】A4 は**縮小版なら**賛成。HP% で自動帰還ラインを設定、全滅時は酒場で蘇生費を払う——ここまでは金貨シンクとして健全。でも「ロスト（永久喪失）」は**反対**。固定キャスト 12 人(#117)で一人ひとりに縁と声を付けたばかりでしょ。その子が理不尽に消えたら、積み上げた愛着が逆効果になる。ロストは任意のハードコアモードに切り出せる日まで見送り。

【レンツ】B1（作戦盤）と B2（図鑑）は「既存流用が効く中規模」グループだ。B1 は酒場の「傾向」`ACTION_PRIORITY` がもう土台にある。「ボスには大魔法/雑魚は通常」「HP 減った味方を優先回復」は、傾向の軸を 2〜3 本足す延長でいける。ただし本格的な「作戦盤 UI」まで作ると二重ファイル同期(index/tavern)と UX 複雑化のコストが乗る。B2 は弱点/耐性データが #75/#76 で既にあるから、遭遇記録を localStorage に貯めて一覧 UI を足すだけ。両方「縮小版で実施」が妥当だ。

【ミサキ】C3（敵バリエーション絵）は……正直、私の領分だけど優先度は低いと言わざるを得ない。同じゴブリンの種別違いを描くのは純粋なアート増産で、codex 発注の枚数がそのまま効いてくる。ゲームロジックの恩恵は薄い。ただし**武器防具アイコンの欠け**を埋めるのは UI の質に直結するし、既存の発注フローで回せる。C3 は「アイコン優先・敵バリエは人気モンスター限定」の縮小版ね。

【ノエル】B3 の連携技は? 掛け合い自体は #118 でもう出てる。

【レンツ】連携技は**新規の戦闘アクション**だから重い。相性ボーナス（相性のいい 2 人を同 PT にすると専用ボイス＋小ボーナス）までが軽い縮小版。連携技本体は A2/A4 が落ち着いて戦闘に余力ができてからだ。

【ガイウス】まとまってきたな。C2（照明と霧）は #39 で出荷済みだから**見送り**——新規性が薄い。やるとしても「神殿で霧に敵のシルエットが浮かぶ」みたいな演出単発の見せ場に切り出せるときだけだ。

# 🎲 トリアージ結論（10 案の仕分け）

凡例: **規模** 小/中/大、**流用度** 高/中/低。実装順は「実施＋縮小版で実施」のものだけに通し番号を付す。

## A. D&D らしさを濃くする案

### A1 呪文スロット制 → 🟡 縮小版で実施
- **理由**: スロット機構(Phase 2-J)は既に完成。提案の核は機構ではなく「ラン単位の希少資源化＝どこで大魔法を切るか」。現状は戦闘ごと自動補充で緊張が薄いので、**回復経済の再チューニング＋酒場休息アクション**で狙いを満たせる。
- **縮小の中身**: ①戦闘勝利ごと 25%／部屋クリア +1 の自動補充を絞る（またはボス前のみ）②酒場に「休息＝全スロット回復」を置く③HUD の残スロット表示を明示化。
- **規模** 小〜中 ／ **流用度** 高 ／ **iOS** クリア（既存 UI 内）。
- **実装順**: ③番目。

### A2 ダンジョン内の技能判定イベント拡充 → 🟢 実施（最優先・Muse 推し）
- **理由**: `SkillCheck` エンジン（DC 表示・クリ/ファンブル・1 部屋 1 ロール）が完成済み。隠し扉＝知覚／崩れ橋＝運動／碑文＝知識は**エンジン流用＋イベントデータ著作**で足せる。sakata 最評価の「ダイス演出」を戦闘外へ広げる直撃案。
- **中身**: 新判定種別（知覚・運動・知識）を SkillCheck に足す→各シナリオへイベント配置→語りテキスト。**失敗時の救済**（見逃しても詰まない／ファンブルのみ軽い被弾）を罠解除のトーン踏襲で必ず設計。
- **規模** 中 ／ **流用度** 高 ／ **iOS** クリア。
- **実装順**: ②番目。

### A3 交渉・威圧・説得の分岐 → 🔴 見送り（縮小の芽は残す）
- **理由**: オートバトルの中核ループへ社交判定を割り込ませる改変で重い。味方化/情報引き出しは敵 AI・報酬・シナリオ分岐すべてに波及し、バランス崩壊と「何が起きたか分からない」UX リスクが大。
- **再検討条件**: A2 が定着したうえで、**「戦闘前の 1 回の説得ロールで戦闘回避 or 有利開始」**という限定スコープに絞れること。既存の隠し要素 NPC（神殿の霊・砦ゴーレム）対話分岐の延長として、特定ボス 1 体に試験導入するのが現実的な第一歩。全面的な敵の味方化はさらに先。

### A4 撤退判断と死亡の重み → 🟡 縮小版で実施（ロストは見送り）
- **理由**: 撤退ボタンは既にある。「HP% 自動撤退ライン」＋「全滅時の蘇生費（金貨）」は**金貨の使い道を作る**既知の課題に合致。ロスト（永久喪失）はオートバトルで理不尽になりやすく、固定キャスト 12 人(#117)の縁の演出と衝突するため外す。
- **中身**: ①撤退ライン設定 UI（出発前に HP%）②敗北/全滅時の蘇生費計算＋酒場の支払い導線。
- **ロスト**: 🔴 見送り。**再検討条件**＝任意のハードコアモードとして本編から分離できるなら。
- **規模** 中 ／ **流用度** 中 ／ **iOS** 要注意（撤退ライン UI のタップ領域）。
- **実装順**: ④番目。

## B. オートバトルを面白くする案

### B1 行動優先度の作り込み（作戦盤） → 🟡 縮小版で実施
- **理由**: 酒場の「傾向」`ACTION_PRIORITY`(#19/#34) が土台。「ボスには大魔法/雑魚は通常」「HP 減った味方を優先回復」は傾向の軸を足す延長で可能。ただし本格 UI は二重ファイル同期(index/tavern)と複雑化のコスト。
- **中身**: 傾向の軸を 2〜3 本追加（対ボス優先呪文／低 HP 回復優先）＋酒場 UI の選択肢拡張。「作戦盤」フル UI は作らず軽い選択で留める。
- **規模** 中 ／ **流用度** 高 ／ **iOS** クリア。
- **実装順**: ⑥番目。

### B2 敵情報の段階開示（図鑑） → 🟡 縮小版で実施
- **理由**: 弱点/耐性データは #75/#76 で既にある。図鑑 UI のみ未実装。遭遇で埋まる図鑑は**既存データ＋localStorage 累積＋一覧 UI**で作れる。
- **中身**: 遭遇記録を localStorage に貯める→酒場 or 戦績画面に図鑑一覧（初遭遇で基本情報、伝承判定成功で弱点/耐性を開示）。
- **規模** 中 ／ **流用度** 高（データ再利用）／ **iOS** 要注意（一覧のスクロール手触り）。
- **実装順**: ⑤番目。

### B3 仲間の性格と掛け合い・連携技 → 🟡 縮小版で実施（連携技は見送り）
- **理由**: 性格と掛け合いは #117/#118/#119 で**出荷済み**。残りは「相性による編成理由」と「連携技」。連携技は新規戦闘アクションで重い。
- **縮小の中身**: 相性のいい 2 人を同 PT にすると**専用ボイス＋小ボーナス**（編成に強さ以外の理由）。
- **連携技**: 🔴 見送り。**再検討条件**＝A2/A4 が落ち着き戦闘に余力ができたら。
- **規模** 小〜中 ／ **流用度** 高（#117 の縁データ流用）／ **iOS** クリア。
- **実装順**: ⑦番目。

## C. グラフィックの拘り案

### C1 クリティカル／ファンブル演出強化 → 🟡 縮小版で実施（Muse 推し・即効）
- **理由**: 画面シェイク(`SHAKE_CRIT`)・クリのダメージポップ拡大・ダイス表示は**実装済み**。提案のうち「画面シェイク」「大きな数字」は済み。未実装は「一瞬のスローモーション／ヒットストップ」。テストプレイ最評価のダイス演出をもう一押し磨く小規模 delta。
- **中身**: クリ/ボス撃破時に短いヒットストップ（数十 ms の停止）＋ポップのさらなる誇張＋SE。既存の⚙設定・`prefers-reduced-motion` ガードに必ず乗せる。
- **規模** 小 ／ **流用度** 高 ／ **iOS** クリア（既存ガード流用）。
- **実装順**: ①番目（最も軽く即効）。

### C2 ダンジョンの照明と霧 → 🔴 見送り（既に出荷済み）
- **理由**: フォグオブウォー `renderLighting`（3 状態）・松明の明かり範囲は #39 で出荷済み。新規性が薄く費用対効果が低い。
- **再検討条件**: 特定シナリオ（神殿／竜の巣）で「視界外の敵シルエットが霧に浮かぶ」など、**演出単発の見せ場**として小タスクに切り出せるなら再検討。

### C3 武器防具アイコン・敵バリエーション画像 → 🟡 縮小版で実施（随時）
- **理由**: 同一モンスターの種別違い絵は純粋なアート増産コスト（codex 発注の枚数が効く）でロジックの恩恵は薄い。一方、武器防具アイコンの拡充は UI の質に直結し既存発注フローで回せる。
- **縮小の中身**: まず**武器防具アイコンの欠けを埋める**→敵バリエーション絵は人気モンスター（ゴブリン/オーク）に限定。
- **規模** ロジック小・アセット中〜大 ／ **流用度** 中（codex パイプライン）／ **iOS** クリア。
- **実装順**: ⑧番目（アート余力のある時に随時）。

# 📌 実装順サマリ（実施＋縮小版の推奨順）
