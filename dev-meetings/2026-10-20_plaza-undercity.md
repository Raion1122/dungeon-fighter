# 開発会議〔第1段：候補出し〕：闇市ポドルプラザの大改修(歩ける地下街 + D&D 由来の品ぞろえ)

**議題**: 闇市を「地下街をうろちょろする」歩ける街の地図にしたい。あわせて、品ぞろえを D&D 由来のアイテムに沿って見直したい。
**ゴール**: 進め方の違う候補を出して、方向を 1 つ選ぶ
(魔法とアイテム 4 本のうち残りの ③ポーション・④ワンドとパールは、品ぞろえの見直しと重なるので、この議題の中で扱い方を決める)

**会議前に測った事実(2026-10-20・HEAD `8a93083`)**
- **今の闇市は「1 枚の重ね画面」**: `tavern.html:3392` の `#plazaScreen`。夜の闇市の一枚絵(`assets/plaza_bg.png`)の上に、折りたためるパネルが 2 枚あるだけ(闇クエスト掲示板 / 闇市商店)。歩く要素は無い。
- **入口は 2 つ**:
  - 銀の鹿亭の怪しい扉(`#plazaDoor`)。
  - 港町フランの「怪しい石段」(`js/town-map.js:151` `{ key: "plaza", enter: [3, 10], via: "plaza" }`)。港町から入ると `sessionStorage["dragonfighters.enterVia"] = "plaza"` を持って `tavern.html` へ移り、闇市の画面が開く。
  - 入場の関門(通常クエスト 5 回で解放・門番・変装の杖 / ポリモーフ習得)はそのまま生きている。
- **歩ける街の前例が 2 つある**:
  - 港町 `town.html`(#12/#15)。地図の絵 `assets/town_phlan.jpg`(23×15 マス・1 マス 64px)、歩ける所のマスク + 経路探索 + 施設 + 立ち位置は `js/town-map.js` が唯一の正、住人の歩き(#41)。⛔ town.html はゲームロジックを持たない(店もクエストも `tavern.html` の中)。
  - 銀の鹿亭の店内(#25・1 マス 96px・`assets/tavern_map.jpg`)。
  - 地図の絵は `codex-map-request` スキルで codex1 の `dnd-map-maker` に発注し、格子へ乗せ直す手順が確立している。
- **闇市の品ぞろえ(牙貨で買う・`PLAZA_ITEMS` / `PLAZA_ITEMS_COMMON` が `index.html:14593` と `tavern.html:5561` の二重定義)**:
  - 目玉 4: スペルターニングリング・ポリモーフ(変装)の杖・スクロール・オブ・クリエイトゴーレム・スクロール・オブ・アニメイトデッド。
  - 一般 4: 影渡りの薬・牙の護符・呪われた曲刀・セリアの手鏡(**4 つとも独自品**)。
  - 全部「回数つきの品」(`plazaInventory`)で、自動で使う合図(`onBattleStartAuto` / `onPreemptiveAuto` / `onEnemySpellAuto` / `onSummon`)が付いている。**装備品は売れない**(装備は別系統 `accessoryIds`。2026-07 の §3 再設計バックログに「橋渡し未設計」と記録済み)。
- **マジックアイテム全体(`gated: true` 21 件・ボスの落とし物 `rollMagicItemDrop` と開発用の店 1G)**: 5e SRD から移した品(フレームタング・フロストブランド・自由の指輪・ガントレットオブオーガパワー・ベルトオブジャイアントストレングス・リング/クロークオブプロテクション・アイズオブジイーグル・クロークオブエルヴンカインド など)と、独自品(聖別された剣・熔鉄の戦鎚・贖罪のメイス・星詠みの杖・風斬りの弓・吸命の短剣・山守りの板金鎧・軽業師の革装束・生命の護符・不浄を退ける聖印・囁きの護符 など)が混ざっている。
- ⚠ **恒久ルール(メモリ)**: 「実在 SRD 品はカタカナ音写。**独自品(第 1〜4 弾)は日本語名のまま改名しない**」。品ぞろえを D&D 由来へ寄せると、このルールとぶつかる可能性がある。
- **ポーション(回復薬)は 1 本も無い**(#96 の前の会議で確認済み)。ワンドオブマジックミサイル・パールオブパワーも無い。

## 第1ラウンド：ブレスト(各専門領域から方向性を 1 つ)

【ガイウス】闇市が「パネルを 2 枚開く画面」なのは、正直もったいない。D&D の闇市は、迷路のような地下街を歩いて、怪しい露店をのぞき、情報屋に袖の下を渡す場所だ。**地下街そのものを 1 つの冒険の舞台にする**。露店ごとに店主が居て、掲示板の依頼人も地下街の奥に立っている。歩いて回ること自体が楽しい場所にしたい。

【レンツ】俺は品ぞろえから。今の闇市の一般品 4 つは全部独自品で、しかも装備品は売れない。**SRD 5.1 の品に置き換えて、「回数つきの品」で表せるものから並べる**。ポーションオブヒーリング、ポーションオブファイアレジスタンス、ワンドオブマジックミサイル、パールオブパワー、ダストオブディサピアランス。積み残しの ③④ がそのまま入る。仕組みは闇市の自動で使う合図をそのまま使える。

【ミサキ】絵の話。港町は明るい昼の港だった。地下街は**松明とランタンの暗がり**でいきたい。歩くと、灯りの届く範囲だけ露店が浮かび上がる。それぞれの店主は、ゴブリンの薬売り、リザードフォークの古物商、ホブゴブリンの両替屋……今の依頼人 3 体の立ち絵も流用できる。

【ノエル】私は手触り。今の闇市は、入って、パネルを開いて、買って、出る。30 秒で終わる。歩ける街にするなら「歩かされる」のが面倒にならないかが心配。港町は、看板を押せばそこまで自動で歩いてくれる。**地下街でも看板 1 タップで店の前まで歩いて、そのまま店が開く**こと。iPhone で片手で済むなら賛成。

## 第2ラウンド：絞り込み(制約で間引く)

【レンツ】地図は前例が 2 つあるから、作り方は迷わない。codex1 に地下街の地図を発注する → 格子に乗せる → マスクを書く → 施設を置く。問題は**店の中身が `tavern.html` にある**ことだ。港町は「ゲームロジックを書かない」の作法で、店は全部 `tavern.html` へ渡している。地下街を `town.html` と同じ別ページにすると、露店を押すたびに `tavern.html` へ移って、闇市の画面が開いて、また地下街へ戻る……になる。

【ノエル】それは嫌だ。ページを移るたびに画面が白く光るでしょう(#85 で直したやつ)。露店 5 軒を回るたびにそれは無理。

【レンツ】だから 2 つの作り方がある。①地下街を `tavern.html` の中の画面として作る(闇市の画面を地図に置き換える)。店とクエストはそのまま同じページで開ける。②別ページにして、店の中身を共有の JS に切り出す。①が軽い。②は正しいが工事が大きい。ここは第 2 段で決める。

【ガイウス】品ぞろえの件、独自品を全部消すのか? 聖別された剣や贖罪のメイスは、シナリオの伏線にも使っている。

【レンツ】そこは決めてもらうしかない。メモリの恒久ルールは「独自品は改名しない」だ。今回の要望は「D&D 由来に沿ったラインナップ」。**闇市の棚だけ SRD に寄せる**のか、**武器防具屋とボスの落とし物まで全部棚卸しする**のかで、仕事の大きさが 3 倍違う。

【ミサキ】独自品を消すと、立ち絵の付いた依頼人と同じで、愛着のある名前がなくなるのが寂しいな。

【ノエル】あと、装備品を闇市で売れないのはどうするの? D&D の店なら、指輪や外套が並んでて当たり前だよ。

【レンツ】それが 2026-07 に積み残した「橋渡し」だ。牙貨で装備品を買えるようにするには、所持の台帳(`accessoryIds` と gated の名前の台帳)へ渡す口を作る必要がある。品ぞろえを広げるなら避けて通れないが、回数つきの品だけで始めるなら後回しにできる。

【ガイウス】地図と品ぞろえ、どちらを先にやる?

【ノエル】画面が変わるのは地図。でも、中身が今の 8 品のままだと、歩いて回っても露店に並ぶ物が少なすぎて寂しい。

【レンツ】そこが本当の論点だ。地図だけ先にやると露店が空っぽ。品だけ先にやると、新しい品を今のパネルに並べることになる。

## 候補①:地下街の地図を先に(品ぞろえは今のまま)
- **ジャンル**: 新エリア(歩ける街)

- **ざっくり規模**: 中〜大(codex1 へ地図の発注 → 格子に乗せる → マスク・施設・住人。店とクエストは今の中身を露店に割り振るだけ)

## 候補②:品ぞろえの見直しを先に(地図は今のまま)

- **狙い**: 闇市の棚を SRD 5.1 の「飲む・使う」品で組み直す。積み残しの ③ポーション・④ワンドとパールをここで一緒に入れる。独自の一般品 4 つは SRD の品へ置き換えるか残すかを決める。

- **推し**: ノエル・レンツ ／ **慎重**: ミサキ(地図ができるまで見た目が変わらない期間が長い)

- **狙い**: 闇市だけでなく、マジックアイテム 21 件(独自品を含む)を SRD 5.1 の品に沿って並べ直す。闇市・武器防具屋・ボスの落とし物の役割分担もここで決める。

# 開発会議〔第2段：実装計画〕：闇市の大改修(露店ごとに品の系統を分け、3 段で進める)

**選択案**: 候補③ + 独自品も全部見直す。
**ゴール**: 段ごとに依頼書 1 枚へ落とせる開発計画書をつくる

**会議前に測った事実(2026-10-20・HEAD `8a93083`・調査役 2 人の報告を本番の行番号で)**
- **所持の記録の鍵が 3 種類ある**(改名と並べ替えの危険度が違う):
  - ゲート付きの武器・鎧 = **名前**(`dragonfighters.ownedGatedNames`。書くのは `markGatedOwned` `index.html:24925` と酒場の `dfAddGatedOwned` `tavern.html:5210`)。⇒ **改名すると古いセーブで持ち物が消える**。移し替えの表が要る。旧セーブの種まき `DF_GATED_LEGACY`(`tavern.html:5181`)/ `DF_SHEET_GATED_LEGACY`(`index.html:20624`)にも名前が 4 つある。
  - 装飾品 = **id**(`dragonfighters.accessoryIds`)。闇市の品 = **id**(`dragonfighters.plazaInventory`)。⇒ 名前の変更は安全。id を変えると消える。
  - 装備の選択 = **配列の番号**(`ownedEquip` / `weaponIdx` / `allyEquip` など)。⇒ **行の並べ替え・途中への挿入は禁止**。ゲート付きの行は武器 3〜5・鎧 3 の位置に固定。
- **独自品の内訳**:
  - 武器: 聖別された剣(戦士)・熔鉄の戦鎚(ドワーフ)・贖罪のメイス(僧侶)・星詠みの杖(魔法使い)・風斬りの弓(エルフ)・吸命の短剣(盗賊)
  - 鎧: 山守りの板金鎧(ドワーフ)・軽業師の革装束(盗賊)
  - 装飾品: 自由の指輪・火耐性の指輪・生命の護符・不浄を退ける聖印・囁きの護符・残影の首飾り(残影の獣の落とし物)
  - ゲートなしの特別な武器: 雷鳴の斧・吸命のメイス・嵐のスタッフ・霜咬みの弓・影縫の刃
  - 闇市の一般品 4: 影渡りの薬・牙の護符・呪われた曲刀・セリアの手鏡
- 名前を文字で持つテストは少ない: `driver_equip_compact_ios.js` と `verify_sheet_equip.js` が戦士の 3 本(フレームタング・フロストブランド・聖別された剣)をセーブの種に直書き。ほかの独自品の名前を持つテストは 0。
- **闇市の品の効き目**: `consumeTrigger` の文字列は**飾りで、どこからも読まれていない**。効き目は id を名指しした関数が持つ(`applyBattleStartConsumables` `index.html:22593` / `tryNegatePreemptive` `:22630` / `tryReflectEnemySpell` / `executeSummon` / 酒場の `onTapPlazaDoor`)。
- **地図の作りの制約**:
  - 闇市の画面 `#plazaScreen` の DOM の形は、`verify_tavern_map` (6c) がコミット `638b479` の形と突き合わせて固定している(差を足すときは `DOM_ADDED` に申告が要る)。
  - 港町と酒場の店内の歩きは**写経された別々の実装**(共有の JS は無い)。住人の歩き(`verify_npc_crowd`)と店内の歩き(`verify_tavern_map`)には「ファイルの中にちょうど 1 回」の文字列アンカーが付いている。⇒ `tavern.html` の中に歩く処理をもう一度写すと、それだけでテストが落ちる。
  - 闇市を出ると、港町から来ても**酒場に落ちる**(`closePlaza` は画面を隠すだけ)。港町の闇市前の立ち位置 `SPAWNS.plaza=[3,11]` は用意されているが、誰も `exitVia="plaza"` を書いていない。
  - 灯りと闇の描画は、ダンジョンの `renderLighting`(`index.html:8362`)にしか無い。港町も酒場も闇市も、灯りの仕組みを持たない。
- 地図の発注先(`codex-map-request`)の `GRIDS` に闇市の行はまだ無い。
- ⚠ 闇クエストの珍しい依頼 2 種(単眼の暴君・隊商護衛)の出現率が、体感テスト用の **1.0** のまま(`tavern.html:10224` / `:10234`。コメント「体感テスト後 0.08 へ戻す」)。

## 第1ラウンド：設計

【レンツ】3 段に割る。段ごとに依頼書 1 枚。
- **段 1 = 薬屋と杖屋**(品の表と、今の闇市のパネルに並べる):
  - 新しく足す品: ポーションオブヒーリング / グレーターヒーリング / ファイアレジスタンス、ワンドオブマジックミサイル、パールオブパワー。
  - 一般品 4 つの置き換え。
  - 今の目玉の SRD 名への寄せ(名前だけ。id は変えない)。
- **段 2 = 地下街の地図**: codex1 へ地図を発注 → 格子に乗せる → マスク → 露店・掲示板・石段・酒場への扉。
- **段 3 = 古物商**:
  - ゲート付きの独自品を SRD の品へ置き換える(セーブの移し替えの表つき)。
  - 牙貨で装備品を買う橋渡し。

段 1 を先にするのは、地図ができたときに露店に並べる物を先に揃えるためだ。

【レンツ】段 1 の仕組み。闇市の品はもう「回数つき」と「id を名指しした効き目の関数」で動いている。足すのは効き目の口 3 つ。
- **HP が半分を切ったら飲む**(ポーション)。ダメージを受けた後の共通の口に 1 本。
- **枠が尽きたら杖を振る**(ワンド)。`mageAI` が攻撃呪文を 1 つも撃てないときに、マジックミサイルを杖の回数で撃つ。
- **枠を 1 つ戻す**(パール)。部屋クリアの小回復(`applyRoomClearHeal`)の隣で、一番重い減った呪文を 1 つ戻す。

【ガイウス】ポーションは持てる本数に上限を付けろ。前の会議でも言った。

【レンツ】種類ごとに 3 本まで。闇市の在庫の仕組みは「1 個体 = 回数の配列」だから、個体の数で縛れる。

## 第2ラウンド：肉付けと衝突

【ガイウス】段 3 の置き換えで、聖別された剣は何になる? SRD にそのままの物は無いぞ。ホーリーアベンジャーは伝説級で強すぎる。

【レンツ】独自品ごとに、SRD の「一番近い品」を当てる表を起草のときに作って、決めてもらう。たとえば:
- 吸命の短剣 → デイガーオブヴェノム
